# Investment Copilot

Marco de análisis de inversiones para acciones y ETFs. La documentación completa de diseño v1.0 se añadirá en la rama `investment-copilot`.

El proyecto organiza el análisis del negocio o fondo, valoración, riesgos, contexto de cartera y seguimiento de fuentes. No ejecuta operaciones ni presenta sus conclusiones como órdenes de compra o venta.
